vtium-fonts: notices

vtium-fonts installs the font sets of vtium's catalog that the console packages leave out, and copies of the fonts that the sets name and that Arch does not package. This file names every font that a set of the catalog names: where the font comes from, its version, its copyright line, its license, and its Reserved Font Name or the attribution its license asks for. The copyright lines are quoted from the font files or from the license files that the fonts' projects publish.

The font sets and layers are text files of vtium, under the MIT License in LICENSE, and COPYING holds vtium's own notices. For each font that vtium-fonts carries, the full text of its license is in this folder, and for Unscii-8, which is in the public domain, upstream's own statement of that. A font that another Arch package installs keeps its license text in that package's folder under /usr/share/licenses.

Unscii-8 2.1
  The set: unscii-icons, which the console packages install and which names the file by its path, /usr/share/fonts/vtium/unscii-8.bdf.
  The file: unscii-8.bdf. The recipe builds it from unscii-8.hex, http://viznut.fi/unscii/unscii-8.hex, with the script hex2bdf.pl from upstream's source archive, http://viznut.fi/unscii/unscii-2.1-src.tar.gz. It runs the line that upstream's Makefile runs: ./hex2bdf.pl --version=2.1 --variant='8' --rows=8 < unscii-8.hex. The script keeps the 2,840 glyphs from U+0000 to U+FFFF with their pixels unchanged, and leaves out the 351 glyphs above U+FFFF, most of them Symbols for Legacy Computing at U+1FB00, as upstream's own PCF font does.
  Version: 2.1, as the file's FONT_VERSION property states.
  Copyright: unscii.txt in the source archive says "Everything made by me (viznut) is in the Public Domain." The file's COPYRIGHT property is empty, because upstream's line passes no copyright.
  License: public domain, in unscii.txt, which is upstream's own text. unscii.txt also says that hex2bdf.pl comes from the Unifont project and is under the GPL. The recipe runs the script to build the font, and vtium-fonts does not install the script.
  Reserved Font Name: none.

Nerd Fonts, which vtium-fonts does not carry
=============================================

vtium-fonts carries no Nerd Fonts file and depends on none. Every Nerd Fonts build, Symbols Nerd Font Mono included, holds the Font Logos icons, the logos of operating systems and projects at U+F300 to U+F385, and Nerd Fonts' license-audit.md lists Font Logos as unlicensed. So the recipe names Arch's Nerd Fonts packages as optional dependencies, which you install yourself. Without a Nerd font, a set draws each Nerd Fonts icon that none of its other sources holds as a hollow box, and a set of the nerd folder draws its text from Unifont.

Symbols Nerd Font Mono 3.4.0, optional
  The layers: nerd-symbols and nerd-symbols-small, which add Powerline's and Nerd Fonts' icons to every set of the console, classic, code, scripts and small folders apart from terminus.
  Source: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0
  Copyright: "Copyright (c) 2016, Ryan McIntyre", as the font states, and the copyright of each icon set, below.
  License: MIT for Nerd Fonts' own work, and each icon set under its own license, below.
  Package: ttf-nerd-fonts-symbols-mono, an optional dependency.

The Nerd Fonts 3.4.0 builds of the sets in the nerd folder, optional
  The sets and their fonts: caskaydia-cove (CaskaydiaCove Nerd Font Mono, from Cascadia Code), fira-code-nerd (FiraCode Nerd Font Mono), hack-nerd (Hack Nerd Font Mono), jetbrains-mono-nerd (JetBrainsMono Nerd Font Mono), monoid-nerd (Monoid Nerd Font Mono), sauce-code-pro (SauceCodePro Nerd Font Mono, from Source Code Pro) and terminess (Terminess Nerd Font Mono, from Terminus (TTF)).
  Source: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0
  Copyright: the copyright line of the font each build is made from, given above for the code fonts; for Terminess, "Copyright (c) 2010 Dimitar Toshkov Zhekov, with Reserved Font Name "Terminus Font"" and "Copyright (c) 2011-2023 Tilman Blumenbach, with Reserved Font Name "Terminus (TTF)"", as Terminus (TTF)'s COPYING states. Nerd Fonts' font patcher, which adds the icons, is "Copyright (c) 2014 Ryan L McIntyre", as Nerd Fonts' LICENSE states. Each icon set keeps its own copyright, below.
  License: the license of the font each build is made from, MIT for the patcher, and each icon set under its own license. CaskaydiaCove, SauceCodePro and Terminess carry names of their own because Cascadia Code, Source Code Pro and Terminus (TTF) reserve theirs.
  Packages, each an optional dependency: ttf-cascadia-code-nerd, ttf-firacode-nerd, ttf-hack-nerd, ttf-jetbrains-mono-nerd, ttf-monoid-nerd, ttf-sourcecodepro-nerd and ttf-terminus-nerd.
