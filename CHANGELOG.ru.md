# Журнал изменений lxappearance-wlr

## 0.6.4-12
- Добавлена Wayland-безопасная галерея предпросмотра курсоров через `libXcursor` без необходимости в X-сервере.
- Ранее скрытый регулятор размера курсора теперь показан на вкладке «Курсор мыши» (у строки слайдера в UI отсутствовал `visible`), диапазон зафиксирован 8–96, предпросмотр обновляется вживую; этот регулятор задаёт `XCURSOR_SIZE`.
- При Apply значения `XCURSOR_THEME` и `XCURSOR_SIZE` дублируются в `~/.config/labwc/environment` с сохранением комментариев и других переменных.
- При Apply под labwc (определяется по `$LABWC_PID`) выполняется `labwc --reconfigure`, чтобы курсор применился без перелогина; другие wlroots-композиторы не затрагиваются.
- Из desktop-файла удалён пустой ключ `NotShowIn=`.
- Текст «Замечания» на вкладке курсора переписан в нейтральном к композитору виде (не все wlroots-композиторы меняют курсор на лету; некоторым нужен перезапуск композитора).
- Добавлены `README.en.md` и `README.ru.md`; они вместе с `AGENTS.md` устанавливаются в `/usr/share/doc/lxappearance-wlr/`.

## 0.6.4-11
- Добавлены popup-подсказки на вкладке `Виджет` (список тем, предпросмотр, шрифт по умолчанию).
- Добавлены переводы этих подсказок в `po/ru.po`, чтобы интерфейс оставался полностью русским.
- Обновлен patch перевода `lxappearance-ru-translation.patch` с новыми строками tooltip.

## 0.6.4-10
- Во вкладке `Шрифт` добавлены равные внешние отступы (включая правый), чтобы контент выглядел как на остальных вкладках.
- Добавлены popup-подсказки с пояснениями для основных параметров шрифтов (сглаживание, хинтование, стиль хинтования, субпиксельная геометрия).

## 0.6.4-9
- Улучшено форматирование вкладки `Шрифт`: строки параметров выровнены, лишние промежутки между подписью и полем уменьшены.
- Добавлены группы выравнивания для подписей и полей в строках хинтования и субпиксельной геометрии.
- Увеличена минимальная ширина выпадающих списков, чтобы значения не выглядели сжатыми.

## 0.6.4-8
- Установлена ширина главного окна по умолчанию `700` для более компактного стартового вида.
- Применение патчей в `prepare()` сделано детерминированным через `git apply --check` + `git apply` (без неявного 3-way fallback).
- Добавлен этап `check()` в PKGBUILD с smoke-проверками ключевых эффектов wlroots/Wayland патчей и наличия собранного бинарника.
- Добавлены рекомендации по сопровождению патчей для дальнейших обновлений.

## 0.6.4-6
- Удалена явная runtime-зависимость `libx11` из метаданных пакета.
- Добавлена легкая диагностика через `g_message` при Apply (сохранение и синхронизация настроек).
- Wayland-патч разделен на `lxappearance-wayland-sync.patch` и `lxappearance-wayland-ui.patch`.

## 0.6.4-5
- В Wayland-ориентированной сборке из интерфейса удалены устаревшие вкладки `Цвет` и `Другие`.

## 0.6.4-4
- При применении настроек `.desktop` для автозагрузки создается в `$XDG_CONFIG_HOME/autostart/` пользователя.
- Убрана установка `.desktop` автозапуска в `/etc/xdg/autostart`.

## 0.6.4-3
- Добавлена немедленная синхронизация gsettings при нажатии Apply (для labwc/Wayland).
- Добавлен helper в автозагрузку для синхронизации GTK-настроек в gsettings при входе.

## 0.6.4-2
- Настройки темы теперь записываются и в `~/.config/gtk-3.0/settings.ini`, и в `~/.config/gtk-4.0/settings.ini`.

## 0.6.4-1
- Пакет переименован в `lxappearance-wlr` для окружений на базе wlroots.
- Сборка оставлена только для GTK3; вариант GTK2 не используется.
- Убран запрет запуска в других DE (`NotShowIn=`).
- Убрана LXDE-специфичная категория (`X-LXDE-Settings`).
- Добавлены changelog на английском и русском в составе пакета.
