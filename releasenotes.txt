# Gaia Sky 3.9.0

This release brings volumetric rendering of the Milky Way, a new SMAA anti-aliasing implementation, a reworked camera, and support for `gaiasky://` URLs, among many more new features and bug fixes.

## Features

### Volumetric rendering
- Add RGBA (color+density) format support to the whole pipeline, from the loader all the way to the shader.
- Support non-cubic volumes. Data such as the Milky Way are not cubic by nature: a flattened grid of `n x m x n` voxels, with `m` much smaller than `n`, uses a small fraction of the memory for the same voxel size.
- Skip empty bricks in the raymarcher with a per-volume occupancy grid of 4x4x4 bricks.
- Crop the unused parts of 3D volumes at load time, to improve memory usage and speed.
- Per-slot occlusion: volumes write depth in a depth-only pre-pass, so dense dust lanes hide the stars behind them while the faint outer haze does not.
- Expose the ray-marching iteration count to the JSON format. It can be a single integer, or an array of four integers for the low, normal, high, and ultra quality settings.
- Improve the default sample volume shader with a normalized sampling volume and jitter.
- Move the galaxy volume shader from the dataset to the repository, as it is general enough to be kept there. Add reference system transformations (`refSysTransform`) to volumes.
- Improve the scripts that convert particle fields to 3D textures: add the RGBA format and a smoothing parameter, accept gzipped inputs, add a script to combine several volumes into one texture and another to render top and side views of a volume, apply the correct rotation, and normalize the output so that the declared sizes are respected.

### Anti-aliasing
- Add SMAA: shaders, presets, area and search textures, and the CPU-side passes. It is now the default anti-aliasing method, and it can be selected in the preferences window with three quality levels.

### Camera & controls
- Rework the camera stop behaviour in cinematic and regular modes to improve responsiveness and damping.
- Camera work when close to planets and other bodies: bound the near-surface damping, decouple the cap from the floor, and use logarithmic speed scaling.
- Add camera damp factor scaler to the camera component, which controls the damping decay of the non-cinematic camera. Modify the default values for camera speed, rotation, and turn.
- Fix focus locking by incorporating the focus delta position into the camera delta position `dCam`.
- Smooth gamepad axis and RB/LB vertical input with a configurable smoothing setting.
- Recalibrate controls in game mode and reduce low-pass smoothing for mouse movement.

### `gaiasky://` URL protocol
- Register and handle the `gaiasky://` protocol on Windows (at install time), Linux (desktop files and `x-scheme-handler`), and macOS. Part of [#935](https://codeberg.org/gaiasky/gaiasky/issues/935).
- Dispatch URLs reflectively through the APIv2, and add the `gaiasky://load?dataset=` protocol. External URLs are accepted automatically if they match any of the data mirrors; otherwise, user confirmation is required.
- Add a single-instance manager, so that a URL forwarded from a second instance, or from a macOS open event, reaches the running application and hot-loads the dataset.
- Add the URL protocol handler dialog, with translations. Fixes [#935](https://codeberg.org/gaiasky/gaiasky/issues/935).
- URL protocol handling on macOS does not rely on the `-XstartOnFirstThread` VM flag anymore, but uses the `glfw_async` mode instead.

### REST server
- Move the REST server from the desktop launcher to the main Gaia Sky core.
- Add a 'REST server' section to the preferences dialog, where the server can be started and stopped with a given port, and the server status and API endpoints are shown.
- Add a setting to enable or disable the loopback-only binding of the REST server. It defaults to `true` for safety, and is exposed in the preferences window.

### Catalogs & objects
- Add version 4 to the binary format, possibly to be used for DR4. It includes astrophysical parameters such as log(g) and metallicity.
- Add initial implementation of Sesame name discovery. Sesame appears at the bottom of the autocomplete list in the search dialog; when selected, the query is sent and the result is shown in a new `SesameResultWindow`. If it succeeds, all names for the object are listed. Part of [#936](https://codeberg.org/gaiasky/gaiasky/issues/936).
- Automatically compute smooth vertex normals for wavefront models without normals in `OwnObjLoader`. Prevents black models with files that only contain vertices and faces.
- Add Phil Nowell's mapping to the cube sphere creator as the default. Precompute the procedural generation model on startup.

### Light glow
- Size each halo from the angular size of the light instead of its intensity, so it grows as the camera approaches a star and stays proportional at any field of view.
- Derive the intensity of each light from its apparent magnitude, on a linear-in-magnitude scale that runs from the faintest glowing star to the Sun at 1 AU.
- Replace the light-glow pre-pass with a depth-buffer test in the post-process filter.
- Restore the time-driven angular mask of the halos, and drive it with the frame-time accumulator so that captures and camcorder recordings animate at the target frame rate.

### Other
- Accept 4 images per dataset, with horizontal scrolling.
- Update the default star visual settings. A new settings version forces the configuration file to be updated.
- Update the installer image to contain only the Gaia Sky logo.
- Make the state vectors to elements script more flexible.

## Bug Fixes

### Rendering
- Fix assorted issues with the recently introduced SMAA, and with the NFAA and FXAA shaders, as part of a global code clean-up.
- Fix the catastrophic cancellation issue in the camera blur shader.
- Camera motion blur: reconstruct world positions by unprojecting with the view depth from the log depth buffer and the projection coefficients, fix the `u_dCam` sign, bind the depth texture to the correct unit, and fix the wrong target buffer index and the incorrect delta camera scaling.
- Camera motion blur star dimming: use a luminance-weighted sample average to preserve the peak brightness of point-like sources along the trail.
- Write constant depth to the depth buffer in the atmosphere shader, so that the motion blur shader reconstructs a consistent world position for all fragments.
- Global label enable flag is now used correctly. It defaults to `true`, and objects can turn it off.
- Fix ringed planet detection when computing the occlusion attribute in the elements group renderer. This prevents stars with accretion discs from getting the incorrect illumination model.
- Fix a crash in the star surface shader. Fixes [#934](https://codeberg.org/gaiasky/gaiasky/issues/934).
- Use emulated double-precision time also for fast-moving particles (epoch=0), such as the rings of Saturn. Fixes [#930](https://codeberg.org/gaiasky/gaiasky/issues/930). Part of [#933](https://codeberg.org/gaiasky/gaiasky/issues/933).
- Fix the double upload of mip level 0 when mip maps are enabled in buffered image texture data.
- Adjust the back-buffer scale slider step from 0.1 to 0.01.
- Fix light glow pop-in by adjusting the minimum halo size, and remove the duplicate light glow fragment shader.

### Dataset manager
- Fix the concurrency issues in dataset updates, and add a popup notification on dataset deletion.
- Serialize dataset extraction with a finish lock. Guard the checksum and extraction behind a `ReentrantLock` so concurrent downloads cannot clash on the shared data directory, while the downloads themselves stay parallel. Part of [#928](https://codeberg.org/gaiasky/gaiasky/issues/928).
- Harden dataset update error handling. Part of [#928](https://codeberg.org/gaiasky/gaiasky/issues/928).
- Fix a crash when a corrupted image is downloaded. Fixes [#929](https://codeberg.org/gaiasky/gaiasky/issues/929).
- Make `TextFormatter` thread-safe by synchronizing the `format()` method. Prevents crashes due to concurrent usage of `MessageFormat`. Part of [#928](https://codeberg.org/gaiasky/gaiasky/issues/928).
- Limit the asset manager update to 2 milliseconds, and fix issues with `isFinishedLoading` in material components.

### UI & interface
- Galaxies added via the UI do not get the parent populated correctly.
- Add a guard for empty object names to prevent NPEs during focus change. Fixes [#931](https://codeberg.org/gaiasky/gaiasky/issues/931).
- Add missing Japanese characters to the character set, and re-generate the fonts.
- The REST server port no longer disappears on the stop event.

### Other
- Security fixes for the URL protocol, the REST server, and dataset downloads.
- Fix the NPE and memory leak when octants fade out, and the thread-safety issues in the camera module. Guard against NPEs in octree nodes.
- The octree loader now correctly sets the object component type of the octree wrapper as 'stars'.
- Fix the extrasolar orbit orientation inheritance.
- `--skip-welcome` when no datasets are present now exits and prints a message, instead of showing the recommended datasets welcome screen.
- Actually reload the shader source code on `CTRL`+`SHIFT`+`Y`, whenever possible.
- Log index name conflicts only to the debug channel.

## Code refactoring
- Decouple the dataset download code from the dataset manager window into its own dataset download service, and use it in the URL handler and in the batch download window. Part of [#935](https://codeberg.org/gaiasky/gaiasky/issues/935).
- Replace the old string model types with a proper enum.

## Build system
- Upgrade to install4j 13.1.1, and add pre-uninstall and post-install scripts to the UNIX installer.
- Update to Gradle 9.8.0.
- Upgrade jCommander to version 3.+.
- Upgrade to oshi 7.4.+, and use the base `oshi-core` instead of `oshi-core-java11`.
- Exclude the x86 LWJGL Windows natives from the build. They are unused, since only x86_64 is supported by Gaia Sky, and they are flagged by Windows Defender as a potential threat.
- Mark the `genVersionFile` task as never up to date, so that it re-runs every time.
