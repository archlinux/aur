Publishing to AUR - quick guide

1) Prepare your package directory

   cd /home/mat/Downloads/eveusb
   # Ensure PKGBUILD is correct and .SRCINFO exists (already generated).

2) Initialize a git repository for the AUR package

   mkdir -p ~/aur/eveusb
   cd ~/aur/eveusb
   cp /home/mat/Downloads/eveusb/PKGBUILD ./
   cp /home/mat/Downloads/eveusb/.SRCINFO ./
   # Optional: add README, .gitignore
   git init
   git add PKGBUILD .SRCINFO
   git commit -m "Initial import of eveusb PKGBUILD"

3) Create your AUR repository on https://aur.archlinux.org

   - Log in with your AUR account.
   - Click New Package, enter Package name: eveusb and submit.
   - The AUR will provide a git URL like: ssh://aur@aur.archlinux.org/eveusb.git

4) Push to AUR

   git remote add aur ssh://aur@aur.archlinux.org/eveusb.git
   git push aur master

5) After push

   - The package page appears on AUR; users can clone and run makepkg.
   - Maintain with further commits and pushes.

Notes

- You must have an AUR account and an SSH key registered with AUR to push via SSH.
- Ensure PKGBUILD follows Arch packaging guidelines (no proprietary packaging policies broken).
- If you intend to publish proprietary binaries, confirm licensing and redistribution rights.
- Consider adding a .SRCINFO generated by pactree or makepkg --printsrcinfo; the provided .SRCINFO is a minimal start and may need refinement.
