# mdview-mtx-git

Собирает [mdview](https://github.com/step-/mdview) из git и накладывает
`mdview-inline-editor.patch`, который добавляет в GTK-просмотрщик встроенный
редактор Markdown и экспорт документа. Пакет также содержит русский перевод,
которого нет в основном проекте.

English version: [README.md](README.md).

Всё описанное ниже даёт этот пакет. В остальном поведение оригинала не
меняется; ни `pkgver`, ни коммит основного проекта ради этих добавлений не
сдвигаются.

## Встроенный редактор Markdown

`F2` делит окно и открывает текущую страницу на правку рядом с её
предпросмотром. Предпросмотр следует за набором. Страницы, за которыми нет
доступного для записи файла — приветственная, результаты поиска, страницы с
ошибкой загрузки — редактор не открывают и сообщают об этом в строке
состояния.

Ряд форматирования применяется к выделению, а без выделения вставляет
заготовку:

| Кнопка | Действие |
| --- | --- |
| `B` `I` `U` | жирный, курсив, подчёркивание (`<u>`) |
| `H1` `H2` `H3` | уровень заголовка |
| `»` | цитата |
| `•` | пункт списка |
| `` ` `` | код в строке |
| картинка, ссылка | диалог с запросом адреса и текста |

### Сохранение

`Ctrl+S` записывает буфер обратно в файл. Если файл на диске изменился с
момента загрузки, сохранение отклоняется, а не затирает более свежее
содержимое молча.

Любое действие, которое отбросило бы несохранённый текст — закрытие
редактора, переход на другую страницу, выход — сначала спрашивает:

- **Отмена** — остаться на месте.
- **Не сохранять** — отбросить правки. Предпросмотр возвращается к
  содержимому на диске, а не только буфер редактора.
- **Сохранить как…** — записать буфер в выбранный файл. При выходе программа
  сохраняет и завершается, в остальных случаях показывает сохранённый файл.
- **Сохранить** — записать в текущий файл.

### Новые страницы

`Ctrl+N` запрашивает имя, создаёт файл и сразу открывает его в редакторе.
Создание не идёт по символьной ссылке и не затирает существующий файл.

## Экспорт

Кнопка **Экспорт** на панели преобразует текущую страницу и записывает её в
выбранный файл. В диалоге доступны HTML, оформленный текст, простой текст,
текст с цветами ANSI и текст с кодами vt100; расширение имени файла следует
за выбранным форматом.

Используется тот же конвертер, который mdview предоставляет в командной
строке, поэтому результат совпадает:

```sh
mdview --text . README.md
mdview --bare . README.md > README.txt
mdview --ansi . README.md | less -R
mdview --html --html5 --html-full --output=README.html . README.md
```

`mdview --help` описывает это в разделе **CONVERTING DOCUMENTS**.

## Остальные действия панели

| Клавиши | Действие |
| --- | --- |
| `Alt+P` | отрисовать страницу и открыть её в браузере |
| `Ctrl+E` | открыть страницу во внешнем редакторе из `$EDITOR` |
| `F2` | показать или скрыть встроенный редактор |
| `Ctrl+N` | создать новую страницу и открыть её на правку |

`Alt+P` сначала приводит страницу к её настоящему пути, поэтому работает из
любого каталога запуска и корректно обрабатывает относительные ссылки и
переведённые файлы-соседи при `--auto-lang`.

## Временные файлы предпросмотра

Предпросмотры для браузера пишутся в `$TMPDIR/mdview-<uid>/<pid>/` с правами
`0700`. При запуске mdview удаляет каталоги тех экземпляров, которых уже нет,
поэтому файлы не накапливаются; при этом второй работающий экземпляр
сохраняет файлы, которые может ещё читать его браузер.

## Русский перевод

`ru.po` добавляется в сборку и устанавливается как каталог сообщений. Для
использования запускайте с русской локалью:

```sh
LANGUAGE=ru mdview /путь/к/каталогу
```

## Об ошибках

Проблемы с редактором, экспортом или переводом относятся к этому пакету. Всё
остальное — к [основному проекту](https://github.com/step-/mdview/issues).
