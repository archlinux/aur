# lxappearance-wlr

Переключатель тем GTK3 (LXAppearance), адаптированный для **Wayland-композиторов на базе wlroots** (labwc, sway, river, Hyprland и т. д.). В репозитории хранятся только `PKGBUILD`, патчи и журналы изменений; апстрим `lxde/lxappearance` (тег `0.6.4`) выгружается и патчится во время сборки.

## Вкладка «Курсор мыши» (0.6.4-12)
- **Безопасный для Wayland предпросмотр** через `libXcursor` (`XcursorLibraryLoadImages`) — файлы темы читаются напрямую, без X-сервера.
- **Видимый регулятор размера** — строка ползунка «Размер курсоров» была скрыта в исходном `.ui`; теперь показана, диапазон зафиксирован 8–96, задаёт `XCURSOR_SIZE`.
- **Apply дублирует курсор в композитор** — `XCURSOR_THEME` / `XCURSOR_SIZE` идемпотентно пишутся в `~/.config/labwc/environment` с сохранением комментариев и других переменных.
- **Живая перезагрузка labwc** — под labwc (задан `$LABWC_PID`) Apply также выполняет `labwc --reconfigure`. Другие композиторы не затрагиваются.

> **Замечание:** не все wlroots-композиторы поддерживают смену темы курсора на лету. На некоторых из них — и на старых версиях labwc — изменения применяются только после перезапуска композитора. Уже запущенные приложения могут сохранять прежний курсор до перезапуска.

## Прочие изменения
- Из desktop-файла убран пустой ключ `NotShowIn=`.

## Куда пишутся настройки при Apply
| Цель | Кто читает | Когда применяется |
| --- | --- | --- |
| `gtk-3.0` / `gtk-4.0/settings.ini` | приложения GTK | при следующем запуске GTK-приложения |
| `gsettings org.gnome.desktop.interface` | GTK / portal-приложения | сразу или при следующем запуске |
| `~/.config/labwc/environment` | labwc и wlroots-композиторы | при следующем старте композитора (labwc — `--reconfigure`) |

## Сборка
```bash
makepkg -fC                         # клонирование, патчи, сборка, check()
updpkgsums                          # обновить b2sums после правки источника
makepkg --printsrcinfo > .SRCINFO   # перегенерировать метаданные
```

Правила патчей и упаковки — в `AGENTS.md`; история релизов — в `CHANGELOG.en.md` / `CHANGELOG.ru.md`.
