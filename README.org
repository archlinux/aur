* NAME
bff - Bitwarden fuzzy finder (not official)

* DESCRIPTION
bff is an unofficial Bitwarden fuzzy finder written in Go.

Go to https://bitwarden.com to support Bitwarden.

* REQUIREMENTS
You must have the Bitwarden CLI installed.

* INSTALLING BITWARDEN CLI
** Arch Linux
#+begin_src sh
yay -S bitwarden-cli
#+end_src

** Debian
#+begin_src sh
sudo apt install bitwarden-cli
#+end_src

* SETUP
** Get session key
#+begin_src sh
bw login --raw
#+end_src

** Store session key
#+begin_src sh
vim ~/sk.txt
#+end_src

Or in one command:

#+begin_src sh
bw login --raw >> ~/sk.txt
#+end_src

* USAGE
#+begin_src sh
bff
#+end_src

#+begin_src sh
bff --name --hidden --not-open --login
#+end_src

* OPTIONS
- *--name* string  
  Find a specific named entry.

- *--hidden*  
  Hide the password output.

- *--login*  
  Jump directly to login.

- *--not-open*  
  Do not ask to open links.

- *--create*  
  Create a new user.

* SECURITY
- encrypted password in user.txt file
- uses bcrypt
- Password need to be 5 letters or more
- uses encryptions on users data
- sk.txt deleted and session-key stored in encrypted file
