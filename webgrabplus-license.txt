WebGrab+Plus License FAQ
========================

LICENSE OVERVIEW:
----------------
- WebGrab+Plus is freeware but CLOSED SOURCE software
- License identifier for PKGBUILD: license=('LicenseRef-custom')

LICENSE TYPES:
-------------
1. Standard (Free):
   - Basic functionality with limitations

2. Donator Status (6€/year):
   - Full performance grabbing
   - Automatic siteini decryption
   - 250 channels / 15 siteini limit
   - Maximum 2 computers

3. Custom License Options:
   - Additional 250 channels: +6€/year
   - Additional 5 siteini files: +6€/year
   - Remove 2-computer limit: +20€/year
   - Special siteini access: +20€/year

ACTIVATION & MANAGEMENT:
----------------------
- License activation requires a "force" update
- In WebGrab++.config.xml, replace "To force a license update; replace this text with the letter f" with "f"
- License allows use on 2 computers maximum by default
- Adding a 3rd computer causes a 12-hour block after which only the newest and one older computer will work
