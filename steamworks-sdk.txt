SteamWorks is built against the headers of Valve's Steamworks SDK 1.32, as in
upstream's builds (https://github.com/rlabrecque/SteamworksSDK, a copy of the
SDK), and links against its libsteam_api.so, which isn't installed: the game
server provides it.
