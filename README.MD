# ayaan-unstable

THE ULTIMATE FETCH TOOL FOR ARCH, BY AYAAN511

🚀 Installs AyaanFetch.exe + OpenHardwareMonitor for ULTRA system flexing  
🧠 Runs with Wine  
🏆 Always grabs the latest GitHub release

## Features

- Legendary AyaanFetch.exe runs via wine
- Full OpenHardwareMonitor support (for extra hardware stats)
- Adds the ayaanfetch command for INSTANT flex
- Automatically sets EPATH=/usr/bin/unstable/ayaanfetch in your .bashrc and .zshrc
- Hype echo so you always know you’re in the UNSTABLE ZONE

---

## Install (AUR way)

git clone https://aur.archlinux.org/ayaan-unstable.git
cd ayaan-unstable
makepkg -si
ayaan-unstable-setup
