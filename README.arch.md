LibreVNA firmware package
=========================

Firmware files are installed in:
  /usr/share/librevna/firmware/

Updating firmware with LibreVNA-GUI
-----------------------------------

1. Start LibreVNA-GUI
2. Connect the LibreVNA device
3. Open:

  Device -> Firmware Update

4. Select the firmware file:

  /usr/share/librevna/firmware/combined.vnafw

Notes
-----

- Do not disconnect power while firmware update is in progress.
- Firmware files must be accessible on the system running LibreVNA-GUI.
