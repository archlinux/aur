## DB Toolkit

Free, open-source and modern cross-platform database management application with database exploration, query execution, data exploration and management, automated backups and lot more.

Official GitHub Repo: https://github.com/db-toolkit/db-toolkit

## Install From Aur Repo

```bash
yay -S db-toolkit
```

## Manual AUR Installation

```bash
sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/db-toolkit.git
cd db-toolkit
makepkg -si
```

<br>

**This is just an Arch Linux (AUR) package for DB Toolkit. The original project is maintained by: https://github.com/db-toolkit/db-toolkit**
