# anthropic-cli-bin

AUR packaging for [`ant`](https://github.com/anthropics/anthropic-cli), the official
command-line interface for the Claude API.

**AUR package:** https://aur.archlinux.org/packages/anthropic-cli-bin

This repository is a mirror of the AUR git repo. The upstream project is developed by
Anthropic; this repo contains only the Arch packaging.

## Install

```sh
paru -S anthropic-cli-bin
```

Or manually:

```sh
git clone https://aur.archlinux.org/anthropic-cli-bin.git
cd anthropic-cli-bin
makepkg -si
```

Then authenticate:

```sh
ant auth login
```

## Why this exists

Upstream publishes a `.pkg.tar.zst` with each release, but it is generated by `nfpm`
rather than from a PKGBUILD, and has two problems:

- The binary is installed to `/usr/ant`, which is not on `PATH`.
- Its `pkgname` is `ant`, colliding with `extra/ant` (Apache Ant). Installing it makes
  pacman believe Apache Ant is present, silently satisfying any dependency on it.

This package fixes both, and additionally ships the shell completions, man page, and
license that upstream's package omits:

```
/usr/bin/ant
/usr/share/bash-completion/completions/ant
/usr/share/fish/vendor_completions.d/ant.fish
/usr/share/zsh/site-functions/_ant
/usr/share/man/man1/ant.1.gz
/usr/share/licenses/anthropic-cli-bin/LICENSE
```

## Conflict with Apache Ant

Both this package and `extra/ant` (Apache Ant) own `/usr/bin/ant`, so they cannot be
installed at the same time. The conflict is declared, so pacman will prompt before
changing anything rather than failing partway through an install.

This package deliberately does **not** declare `provides=('ant')` — doing so would let it
silently satisfy a dependency meant for Apache Ant.

All 17 packages in the official repositories that depend on `ant` do so as a *make*
dependency, so removing Apache Ant does not break any installed software. It only matters
if you build those packages from source.

## Updating

`update.sh` bumps the package to a new upstream release: it resolves the version, fetches
upstream's published checksums for all four Linux architectures plus the license, rewrites
`PKGBUILD`, and regenerates `.SRCINFO`.

```sh
./update.sh          # latest release
./update.sh 1.22.0   # a specific version
```

Then verify and publish:

```sh
makepkg -f
git commit -am "Update to $(grep -oP '^pkgver=\K.*' PKGBUILD)"
git push            # AUR
git push github     # this mirror
```

Note that checksums are taken from upstream's `checksums.txt` over HTTPS. This verifies
integrity, not provenance — standard for a `-bin` package, but worth knowing.
