# llavon-ime-fcitx5-preview-git

Package metadata for [`llavon-ime-fcitx5-preview-git`][aur] in the Arch User Repository.

This package tracks the `preview` branch of `llavon-ime/ime-fcitx5`. It may
contain features that have not reached `main` and conflicts with the regular
`llavon-ime-fcitx5-git` package.

GitHub Actions builds and tests the Unix service and Fcitx5 addon before
publishing each preview branch update to AUR.

The package downloads and installs the bundled GGUF model at
`/usr/share/llavon-ime/models/llavon-ime-llama-250m-Q4_K_M.gguf`.

[aur]: https://aur.archlinux.org/packages/llavon-ime-fcitx5-preview-git
