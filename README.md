# minitone

TUI music player — search and play from YouTube, Radio Browser, Navidrome (Subsonic), your local library, and favorites.

![minitone](https://raw.githubusercontent.com/ldgnu/minitone/master/assets/banner.png)

![demo](https://raw.githubusercontent.com/ldgnu/minitone/master/assets/demo.gif)

## Install

```bash
yay -S minitone        # build from source
# or
yay -S minitone-bin    # prebuilt binary
```

One-liner:

```bash
curl -fsSL https://raw.githubusercontent.com/ldgnu/minitone/master/scripts/install.sh | sh
```

Requires `mpv`; `yt-dlp` for YouTube. See the [main repo](https://github.com/ldgnu/minitone) for full docs.
