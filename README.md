# Instale a SalopBar no seu ArchLinux com Hyprland

**Clone este repositório:**

```bash
git clone https://github.com/HelenoSalgado/aur.salopbar.git
```

**Entre no repositório clonado**:

```bash
cd aur.salopbar
```

**Execute o makepkg compilador e instalador**:

```bash
makepkg -si
```

*Instale eventuais dependências faltantes com `pacman` e `yay` ou `paru`*.

Para mais informações, visite o [repositório oficial](https://github.com/HelenoSalgado/salopbar).
