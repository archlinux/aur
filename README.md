# orca-ide

[Orca](https://github.com/stablyai/orca) —— Stably AI 的并行 agent 开发环境（Electron），
从上游 GitHub Releases 的 deb 安装包打包。

## Install

```bash
paru -S orca-ide
```

与 AUR 上同一上游的 `orca-ide-bin`、`onorca-bin`、`stably-orca`、`stably-orca-bin`、
`stably-orca-git` 互斥，安装时会自动替换。
