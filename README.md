# cynix-lsb-release

Custom Cynix Linux distribution information

## Description

This package provides a customized /etc/lsb-release file with distribution information for Cynix Linux. It includes the following details:
- Distributor ID: Cynix
- Release: 1.0
- Codename: cynix_codename
- Description: Cynix Linux

## Installation

You can install this package from the Arch User Repository (AUR) using your preferred AUR helper. For example, using yay:

```bash
yay -S cynix-lsb-release
```
