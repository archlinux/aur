# cfgprf

tool for exporting and importing files in ~/.config, packages and AUR packages for Arch Linux.

install with:
```
yay -S cfgprf
```
or
```
paru -S cfgprf
```

usage:
```
cfgprf --export --profile ~/myconfig.cfgprf
# and
cfgprf --import --profile ~/myconfig.cfgprf
```
