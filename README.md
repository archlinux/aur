# 🐱 KoteyScanner

```
    /\_/\  
   ( o.o ) 
    > ^ <  
```

**Многофункциональный порт-сканер с котиком** - красивый, быстрый и удобный инструмент для сетевого сканирования.

## ✨ Особенности

- 🎨 **Красивый цветной интерфейс** с ASCII-котиком
- ⚡ **Многопоточное сканирование** до 1000 потоков
- 🎯 **Множество типов сканирования**: TCP, UDP, HTTP, HTTPS
- 📊 **Прогресс-бар** в реальном времени
- 🔍 **Определение сервисов** и захват баннеров
- 💾 **Экспорт результатов** в JSON, CSV, текстовый формат
- 🚀 **Высокая производительность** и гибкие настройки

## 🛠 Установка

### Arch Linux (с PKGBUILD)
```bash
makepkg -si
```

### Ручная компиляция
```bash
g++ -std=c++11 -pthread -O2 koteyscanner.cpp -o koteyscanner
sudo mv koteyscanner /usr/local/bin/
```

## 🚀 Использование

### Основные команды

```bash
# Базовое сканирование
koteyscanner -h google.com -p 80,443

# Сканирование диапазона портов
koteyscanner -h 192.168.1.1 -p 1-1000

# Топ популярных портов
koteyscanner -h example.com --top-ports 100

# Полное сканирование всех портов
koteyscanner -h 10.0.0.1 --all-ports --threads 200

# С определением сервисов
koteyscanner -h target.com -p 1-1000 --service-detection -v

# Сохранение в JSON
koteyscanner -h server.com -p 80,443,22 -o results.json --format json
```

## 📋 Параметры командной строки

### Основные параметры
| Параметр | Описание | Пример |
|----------|----------|---------|
| `-h, --host` | Целевой хост | `-h google.com` |
| `-p, --ports` | Порты для сканирования | `-p 80,443,22` или `-p 1-1000` |
| `-t, --type` | Тип сканирования | `-t TCP` (TCP/UDP/HTTP/HTTPS) |

### Производительность
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--threads N` | Количество потоков | 50 |
| `--timeout MS` | Таймаут в миллисекундах | 3000 |
| `--delay MS` | Задержка между запросами | 0 |

### Специальные порты
| Параметр | Описание |
|----------|----------|
| `--top-ports N` | Сканировать топ N популярных портов |
| `--all-ports` | Сканировать все 65535 портов |

### Вывод и опции
| Параметр | Описание |
|----------|----------|
| `-v, --verbose` | Подробный вывод |
| `-o, --output FILE` | Сохранить результат в файл |
| `--format FORMAT` | Формат вывода (text/json/csv) |
| `--no-ping` | Не пинговать хост перед сканированием |
| `--no-progress` | Отключить прогресс-бар |
| `--service-detection` | Определение сервисов на портах |

## 🎯 Примеры использования

### Быстрое сканирование веб-сервера
```bash
koteyscanner -h example.com -p 80,443,8080,8443 -t HTTP --service-detection
```

### Сканирование локальной сети
```bash
koteyscanner -h 192.168.1.1 --top-ports 50 --threads 100 -v
```

### Полное сканирование с сохранением
```bash
koteyscanner -h target.com -p 1-65535 --threads 500 -o full_scan.json --format json
```

### Стелс-сканирование с задержками
```bash
koteyscanner -h sensitive-server.com -p 1-1000 --delay 100 --threads 10
```

## 📊 Форматы вывода

### Текстовый (по умолчанию)
Красивый цветной вывод в консоль с прогресс-баром и детальной информацией.

### JSON
```json

  "host": "example.com",
```

## ⚡ Оптимизация производительности

### Рекомендуемые настройки для разных сценариев:

**Быстрое сканирование:**
```bash
--threads 200 --timeout 1000
```

**Надежное сканирование:**
```bash
--threads 50 --timeout 5000 --delay 10
```

**Массивное сканирование:**
```bash
--threads 1000 --timeout 500 --no-progress
```

## 🚨 Ответственное использование

⚠️ **Важно**: Используйте KoteyScanner только для:
- Аудита безопасности ваших собственных систем
- Авторизованного тестирования на проникновение
- Образовательных целей в контролируемой среде

Не используйте для несанкционированного сканирования чужих систем.

## 🐛 Известные ограничения

- UDP сканирование может быть менее точным из-за природы протокола
- Некоторые firewall могут блокировать или замедлять сканирование
- SYN сканирование требует root привилегий (пока не реализовано)
