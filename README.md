# ls3d-installer-aur-git

This AUR package installs the official installer script for **Learnspace 3D** (ls3d) on Arch-based systems.  
It fetches the `installScript.sh` from the official GitHub repository and makes it available as an executable command: `ls3d-install`.

## Usage

The Post installation Script should install everything. Otherwise simple run "ls3d-install"
