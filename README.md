# Cleaner Advanced

Cleaner Advanced is a simple system cleaning program for Arch Linux users, developed in Bash.

## Features

- Cleans Pacman cache
- Removes orphaned packages
- Cleans system journal
- Cleans temporary files
- Cleans Paru cache
- Removes orphaned configuration files

## Usage

To use Cleaner Advanced, simply download the files and run the script `cleaner_advanced.sh` in your terminal. Follow the on-screen instructions to choose the language and select the cleaning options.

For installation:

To use Cleaner Advanced, follow these steps:

Download: Download the latest release of Cleaner Advanced from the Releases page of this repository.

Extraction: Once the download is complete, extract the contents of the downloaded ZIP file to a location of your choice on your system.

Permissions: Ensure that the cleaner_advanced.sh script has execute permissions. You can do this by running the following command in the terminal:

    chmod +x ~/cleaner_advanced.sh

Desktop Entry: Optionally, you can create a desktop entry for Cleaner Advanced to easily launch it from your desktop environment. Copy the provided .desktop file to ~/.local/share/applications/:

    cp ~/cleaner_advanced.desktop ~/.local/share/applications/

Usage: You can now launch Cleaner Advanced by searching for it in your application launcher or by running the cleaner_advanced.sh script from the terminal.
