# agelessd AUR package

This repository holds the pkgbuild, as well as other related files, for installing
`agelessd-flagrant`.

This package pulls the `become-ageless.sh` script from https://agelesslinux.org/
and makes the user "ageless" by destroying age-check APIs as well as leaving
non-compliancy notices. This version, is the "flagrantly non-complying" option.

Please see [the official website](https://agelesslinux.org/) for more information.
