# PearPass

PKGBUILD for PearPass binary AUR package.

## What is PearPass?

> PearPass is a secure password, identity, and creditcard, notes and custom field storage
> it brings privacy and data ownership to users
> with peer-to-peer sync and end-to-end encryption it will give you offline access to your credentials

More information can be found [here](https://pass.pears.com).

## AUR

The AUR package can be found [here](https://aur.archlinux.org/packages/pearpass-bin/).x
