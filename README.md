# MongoDB Compass Stable (AUR)

**Stable, clean and keyring-free build of MongoDB Compass for Arch Linux and derivatives.**

This package installs the official MongoDB Compass binary directly from MongoDB’s `.deb` release, 
without any dependency on NodeJS, Electron build steps or GNOME Keyring.  
Perfect for users of lightweight environments like **Hyprland, Sway, i3, bspwm**, or minimal systems.
