# zsh-komander
zsh-komander - это минималистичная оболочка для zsh.

Суть её в том что вместо того чтоб захламлять консоль огромными и жирными промптами, как допустим в oh my zsh часто бывают излишне больше индикаторы запросов, zsh-komander делает просто маленький промпт: `> _`.
Можно сказать что это не удобно, ведь как я увижу путь где я сейчас нахожусь? А все просто, есть в командире сочитания клавиш которые будут выводить больше информации:
- `Alt+Z` - вывод имени пользователя.
- `Alt+X` - вывод имени компьютера.
- `Alt+C` - вывод пути нахождения в данный момент.
- `Alt+V` - вывод виртуального пространства подключенного в данный момент, если его нет то будет `(null) > _`.
