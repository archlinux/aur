# z-code

[ZCode](https://zcode.z.ai/) —— Z.ai 官方的 AI 编码智能体桌面应用（Electron）。

## Install

```bash
paru -S z-code
```

与 AUR 上已有的 `zcode`、`zcode-bin`、`z-code-bin` 互斥，安装时会自动替换。
