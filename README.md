# LANDrop AUR Package

This is an AUR package for [LANDrop](https://landrop.app/), a tool that allows you to easily transfer files between devices on your local network.

## Description

LANDrop is a cross-platform tool that enables you to transfer files between devices on your local area network (LAN) without the need for internet access or third-party services. It provides a simple and intuitive interface for sending files to other devices running LANDrop.

## Features

- Transfer files between devices on the same network
- Cross-platform support (Windows, macOS, Linux, Android, iOS)
- No internet connection required
- End-to-end encryption
- Simple and intuitive interface

## Installation

```bash
yay -S landrop-bin
```

or

```bash
git clone https://aur.archlinux.org/landrop-bin.git
cd landrop-bin
makepkg -si
```

## Usage

After installation, you can launch LANDrop from your application menu or by running `landrop` in your terminal.
