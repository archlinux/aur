# **Rclone-WIZ**
### Version: 1.5

**Rclone-WIZ is an independent project and is not affiliated with, endorsed by, or sponsored by the rclone team / contributors.**





## Features
- Simple interface
- Built-in `rclone config` launcher for easy setup.
- Step-by-step tutorial for Google Drive authentication, just as an example.
- Auto-generates mount scripts for persistent usage.
- Configure autorun with just a button

## Prerequisites
- `rclone` installed
- `fuse3` installed
- `python-pyqt6` installed

## RUN
1. Clone the repository: `git clone https://github.com/themix88/Clone-WIZ`
2. Navigate to the directory: `cd Clone-WIZ/Rclone-WIZ`
3. Run the application: `python3 rclone-wiz.py`

## OR INSTALL (Manually)

1. Clone the repository: `git clone https://github.com/themix88/Clone-WIZ`
2. makepkg -si

### **OR INSTALL with any (AUR) helper or package manager like Shelly (GUI) or yay / paru.**
