# wiksr

Terminal instant answer browser. Ask questions directly from your terminal — gets answers from DuckDuckGo Instant Answers, falling back to Wikipedia.

## Usage

```
wiksr
```

Then type any question at the `?` prompt. Type `q` to quit.

## Examples

```
? capital of France
? who is Ada Lovelace
? speed of light
```

## Dependencies

- Python
- [python-rich](https://archlinux.org/packages/extra/any/python-rich/)

## Install

```
yay -S wiksr
```
