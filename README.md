## Included Files & Assets

- `PKGBUILD`: Arch Linux package build script.
- `.SRCINFO`: Machine-readable package metadata generated by `makepkg --printsrcinfo`.
- `push_to_aur.sh`: Automation helper to regenerate checksums, `.SRCINFO`, and sync to AUR.
- **Application Icons & Metadata**:
  - `assets/malama.png` (256x256 icon)
  - `assets/malama.svg` (Scalable vector icon)
  - `assets/org.magpiny.malama.metainfo.xml` (AppStream metadata)
  - `build/malama.desktop` (XDG desktop entry)

## Local Build & Validation

To test the package build locally on Arch Linux:

```bash
cd PKGBUILD
# Download source, build, and test installation
makepkg -si
```

To run static analysis with `namcap`:

```bash
namcap PKGBUILD
namcap malama-*.pkg.tar.zst
```

## Release & Update Strategy for AUR

1. **Tag & Release on GitHub**:
   - Push a Git tag (`git tag v0.3.0 && git push origin v0.3.0`).
   - GitHub Actions CI/CD automatically runs test suites, builds packages, and publishes the release tarball.

2. **Update PKGBUILD Version & Checksums**:
   - Bump `pkgver=0.3.0` and reset `pkgrel=1` in `PKGBUILD`.
   - Update checksums using `updpkgsums`.
   - Regenerate `.SRCINFO`:
     ```bash
     makepkg --printsrcinfo > .SRCINFO
     ```

3. **Push to AUR**:
   ```bash
   # Clone the AUR repository via SSH
   git clone ssh://aur@aur.archlinux.org/malama.git /tmp/aur-malama

   # Copy updated PKGBUILD and .SRCINFO
   cp PKGBUILD .SRCINFO /tmp/aur-malama/

   # Commit and push
   cd /tmp/aur-malama
   git add PKGBUILD .SRCINFO
   git commit -m "Update to v0.3.0"
   git push origin master
   ```
