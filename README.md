# Cherry Studio AUR Package
---
This repository contains the AUR package for [Alma](https://github.com/yetone/alma-releases), designed to facilitate installation and management for Arch Linux users.

### Manual Installation
1. Clone the repository:
```bash
git clone https://aur.archlinux.org/alma-appimage.git
cd alma-appimage
```
2. Build and install using `makepkg`:
```bash
makepkg -si
```
