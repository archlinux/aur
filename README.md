# bulk-rename-py

Bulk Rename Py is a graphical Python application for renaming files in bulk, featuring a preview-based workflow, undo support, and flexible naming patterns.

## Installation

Install using your preferred AUR helper.

Or manually:

```bash
git clone https://aur.archlinux.org/bulk-rename-py.git
cd bulk-rename-py
makepkg -si
```

## Notes

- This package installs the application system-wide.
- A desktop entry (`bulk-rename-py`) is provided.
