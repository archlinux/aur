# nmail-bin

[nmail](https://github.com/d99kris/nmail) — terminal-based email client (IMAP/SMTP).

Prebuilt binary from upstream releases, no compilation.

## Install

```sh
makepkg -si
```

Or with an AUR helper:

```sh
yay -S nmail-bin
```

## Dependencies

- file, python
- optional: w3m, pandoc, lynx, elinks (HTML rendering), discount (Markdown), aspell/ispell (spell check)

Upstream project: [https://github.com/d99kris/nmail](https://github.com/d99kris/nmail)
