# Zijiang POS80 AUR Driver

This is an Arch Linux AUR (Arch User Repository) script based on the original `zijiang-pos58-driver` project by Alexander Sulfrian.

**Original Project:** [https://aur.archlinux.org/packages/zijiang-pos58-driver](https://aur.archlinux.org/packages/zijiang-pos58-driver)

## Changes

This script modifies the printer driver from the POS58 model to the **POS80** model.

## How to Use

Please refer to the original project's instructions for building and installing, keeping in mind the driver change for POS80.# zijiang-pos80-aur-driver
