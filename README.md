# aur-atmosphera

AUR for [Atmosphera](https://github.com/alexindigo/atmosphera) (release version).

## Install

```bash
# Clone and build
git clone https://github.com/alexindigo/aur-atmosphera.git
cd aur-atmosphera
makepkg -si
```

When AUR is available, install via your AUR helper:

```bash
yay -S atmosphera
```
