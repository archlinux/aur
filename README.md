# rustmusic

[RustMusic](https://github.com/LingyunStudio/RustMusic) —— 用 Rust + Tauri 编写的音乐播放器，
从上游 GitHub Releases 的 deb 安装包打包。

## Install

```bash
paru -S rustmusic
```

当前仅提供 x86_64：上游暂只发布 `amd64` deb。arm64 版本待上游跟进。
