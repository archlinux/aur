# termimus-ssh-bin

## 📦 Instalasi

### Menggunakan AUR Helper

```bash
# Menggunakan yay
yay -S termimus-ssh-bin

# Atau menggunakan paru
paru -S termimus-ssh-bin
```

### Manual (makepkg)

```bash
git clone https://aur.archlinux.org/termimus-ssh-bin.git
cd termimus-ssh-bin
makepkg -si
```

---

## 🚀 Menjalankan Aplikasi

Setelah terpasang, aplikasi dapat dijalankan melalui menu aplikasi desktop atau via terminal:

```bash
termimus
# atau alias
termimus-ssh
```
