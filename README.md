# bazi-cli（命理精研）

> v2.0.0 起由 Rust 命令行工具升级为图形桌面应用。

中国传统命理研习桌面应用，古朴典雅，完全本地运行、无需联网。

## 功能

- **八字详盘**：四柱、十神、藏干、纳音、大运流年
- **紫微斗数**：安命身宫、五行局、紫微主星与辅星、四化、大限（闰月按下月派）
- **黄大仙灵签**：完整一百签签文与典故
- **周易六十四卦**：时间起卦（梅花易数）/ 铜钱摇卦 / 查卦，本卦、变卦、动爻爻辞
- **AI 提示词**：一键导出命盘结果，粘贴给任意 AI 深入分析

## 安装

```
yay -S bazi-cli
```

安装后：

- 命令 `destiny_cn` 或 `bazi-cli` 启动
- 桌面环境应用菜单中搜索「命理精研」

## 说明

- 本包使用上游 [GitHub Release](https://github.com/Paul-sinbud2004/bazi-cli/releases) 预编译二进制，安装无需现场编译。
- 旧版 Rust CLI（1.0.0）源码保留在上游仓库 `legacy-v1-rust` 分支。
