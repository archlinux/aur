# plasma6-applets-codexbar-git

AUR package for the development version of
[CodexBar for KDE Plasma](https://github.com/mirsella/codexbar-plasmoid).

## Install

```sh
paru -S plasma6-applets-codexbar-git
```

The package tracks the `main` branch of the fork and uses the standard
`com.github.psimaker.codexbar` Plasma package ID.
