# wiksr

Terminal instant answer browser. Ask questions or type terms into your terminal and receive a brief summary or definition.

## Usage

```
wiksr
```

Then type any question at the `?` prompt. Type `q` to quit.

## Examples

```
? capital of France
? who is Ada Lovelace
? speed of light
```

## Dependencies

- Python
- [python-rich](https://archlinux.org/packages/extra/any/python-rich/)

## Install

```
yay -S wiksr
```
