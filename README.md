# nchat-bin

[nchat](https://github.com/d99kris/nchat) — console-based chat client (Telegram, WhatsApp, Signal).

Prebuilt binary from upstream releases, no compilation.

## Install

```sh
makepkg -si
```

Or with an AUR helper:

```sh
yay -S nchat-bin
```

## Dependencies

- file, ncurses, openssl, python, sqlite, zlib

Upstream project: [https://github.com/d99kris/nchat](https://github.com/d99kris/nchat)
