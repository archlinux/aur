# AUR Package for l

This is the AUR (Arch User Repository) package for [l](https://devan.gg/l).

The package is named `l` but installs the binary as `l`.

## Installation

### Using an AUR helper (recommended)

```bash
yay -S l
# or
paru -S l
```

### Manual installation

```bash
git clone https://aur.archlinux.org/l.git
cd l
makepkg -si
```

## Usage

After installation, use the `l` command:

```bash
l --help
```

## Updating

```bash
yay -Syu l
# or
paru -Syu l
```

## Uninstall

```bash
sudo pacman -R l
```
