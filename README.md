# intel-deep-learning-essentials-bin

AUR package for [Intel® Deep Learning Essentials](https://www.intel.com/content/www/us/en/developer/tools/oneapi/deep-learning-essentials.html), a subset of the Intel oneAPI toolkit for PyTorch and TensorFlow on Intel CPUs/GPUs.

This package exists because the AUR only offers the full 13GB+ oneAPI toolkit. This installs only the essentials (~1.4GB download, ~6.4GB installed).

## Installation

```bash
yay -S intel-deep-learning-essentials-bin
```

## Usage

```bash
source /opt/intel/oneapi/setvars.sh
```
