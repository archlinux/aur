# MonoLisa Fonts

MonoLisa is a font created by Marcus Sterz, Juho Vepsäläinen and Andrey Okonetchnikov.
The Font can be obtained from https://www.monolisa.dev

## IMPORTANT
Please note that this PKGBUILD ships with an empty `monolisa-fonts.tar.gz` file, it is meant to be replaced by a tar file created by the the user.

### Steps before building the package:
1. Download the fonts from https://www.monolisa.dev
2. Rename the downloaded zip to `monolisa-fonts.tar.gz`
3. Build the package
