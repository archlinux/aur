# plasticity-4arch — AUR package for Plasticity with a working loader fix

AUR repackage of the official upstream [Plasticity](https://github.com/nkallen/plasticity) `.deb`
(3D modeling software for concept artists) plus a build-time loader fix that actually makes it run on Arch.

## Why (3 lines)

- The official `.deb` ships `pk.node` (Plasticity Kernel, Parasolid-based) with **no RPATH**; it `dlopen()`s `libA3DLIBS.so` (176 MB Parasolid lib) by **bare name** at runtime.
- On Arch the dlopen fails → **SIGABRT right after license activation** → a windowless main process holds Electron's single-instance lock → every later launch exits silently with `MAIN: Lock taken`.
- **Fix:** set `RPATH=$ORIGIN` on the kernel module(s) that reference `libA3DLIBS.so`, at build time in `package()`. Lib and caller are colocated, so `$ORIGIN` is install-prefix-independent and works for every launcher (Plasma icon, terminal, systemd) — unlike `.desktop Environment=`, which Plasma ignores.

## Prerequisites

- `makepkg` (`base-devel`), `patchelf`, `ar` (binutils), `curl`, `sha512sum`, `strings`, `bash`
- `jq` optional (nicer API parsing in `update.sh`; a grep/sed fallback exists)
- Missing? `sudo pacman -S base-devel patchelf`

## Quickstart

```bash
cd "<workdir>/aur"
./update.sh                                    # resolve latest, fetch, checksum, canary, render PKGBUILD, build
sudo pacman -U plasticity-4arch-<ver>-1-x86_64.pkg.tar.zst
cd ..
./plasticity-fix.sh --verify                   # bare-launch via systemd-run + log assertion + clean stop
```

## Update workflow

`./update.sh` is the whole workflow and is self-contained in this directory:

1. Resolves the latest GitHub release (or pin with `--version X`).
2. No-ops if `PKGBUILD` is already at that version (`--force` to override).
3. Downloads `plasticity_<ver>_amd64.deb` + `LICENSE` into this directory — makepkg's source dir — so `makepkg` reuses them and does not re-download.
4. Computes sha512 checksums and runs a **canary** that aborts loudly if upstream moved `libA3DLIBS.so` or the `.node` modules (and prints the future patch-target list).
5. Renders `PKGBUILD` from `PKGBUILD.template` with real values, then `makepkg -fC --skippgpcheck`.
6. Proves the built `.pkg` carries the fix (`RPATH=$ORIGIN` on `pk.node` et al.) by extracting it — no install needed.

Useful flags: `--no-build` (steps 1–5, no makepkg), `--test` (print install+verify procedure), `--test --install` (auto-install + `../plasticity-fix.sh --verify` ONLY when passwordless sudo AND a live user session are both available; otherwise it prints the exact commands to run by hand — observed behavior on this box, see BUILD-LOG N5).

After a good build: install, verify, `git add aur/ && git commit`, then submit to AUR — the name `plasticity-4arch` was confirmed available on 2026-08-26 (web fallback; see BUILD-LOG Phase 4).

## Switching over from plasticity-bin (AUR users)

`plasticity-4arch` and `plasticity-bin` **cannot coexist**: both install the same `/usr/lib/plasticity/*` files, so remove the other one first.

1. Close Plasticity and save your work.
2. Kill any lingering windowless `plasticity` process — a stuck windowless instance holding Electron's single-instance lock is the documented failure mode.
3. Remove the stale `Singleton*` lock files in `~/.config/Plasticity` (e.g. `rm -f ~/.config/Plasticity/Singleton*`).
4. `sudo pacman -Rns plasticity-bin`
5. `pacman -S plasticity-4arch` (AUR helper equivalent: `yay -S plasticity-4arch`)

Your license in `~/.plasticity` is not package-owned and survives the swap.

## File map

| File | Role |
|---|---|
| `PKGBUILD.template` | Source of truth; placeholders `@PKGVER@`, `@SHA512_DEB@`, `@SHA512_LICENSE@` |
| `PKGBUILD` | Rendered copy (generated by `update.sh`; do not hand-edit) |
| `apply-loader-fix.sh` | **The fix** — `apply_loader_fix <payload-root> [--with-ld-fragment]`; sourced by `package()` |

| `.gitignore` | Keeps downloaded inputs and build artifacts out of git |
| `BUILD-LOG.md` | Build journal (prereqs, validation results, errors) — source of truth for handovers |
